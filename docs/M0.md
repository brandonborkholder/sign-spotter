# M0 integration proof

Status: complete

Completed: 2026-08-31

## Decision

Use direct browser-to-PublicStuff API calls for the MVP. Keep the official
Loudoun County form as a manual fallback. A proxy is not currently needed.

## Evidence

- The deployed GitHub Pages probe read both legacy metadata endpoints from
  `https://brandonborkholder.github.io` with HTTP `200` responses.
- Request type `1011942` and its required custom fields were discovered from
  live PublicStuff metadata.
- A legitimate report established the exact multipart field names, ordering,
  custom-field JSON encoding, duplicate `client_id`, photograph field, and
  successful response shape.
- The upload endpoint's preflight returned HTTP `200` with:
  - `Access-Control-Allow-Origin: *`
  - `Access-Control-Allow-Methods: PUT, GET, POST, DELETE, OPTIONS`
  - `Access-Control-Allow-Headers` including `PublicStuff-Client`,
    `PublicStuff-Session-Token`, `Content-Type`, and `Authorization`.
- The successful POST returned `response.status.code: 200` and a numeric
  `response.request_id`.
- Request type `1011942` requires a PublicStuff account. The legitimate report
  required account creation and login before submission, and the successful
  request carried the returned `api_key` as a private session credential.

## Captured artifacts

- `docs/publicstuff-request-submit-redacted.txt`
- `docs/publicstuff-request-submit-response.json`

The original cURL, contact values, image data, and session credential are not
stored in the repository.

## Implementation facts for M1/M2

- API origin: `https://vc0.publicstuff.com`
- Submit endpoint: `/api/2.0/request_submit`
- Header: `PublicStuff-Client: 1295`
- Request type: `1011942`
- Space: `40448`
- Issue choice: `custom_field_25876 = JSON.stringify("Illegal signs")`
- Contact privacy choice:
  `custom_field_42345 = JSON.stringify("Yes" | "No")`
- Contact fields `6185`, `6186`, `6187`, and `6225` are required.
- First-use setup must log in to an existing PublicStuff account, retain the
  returned `api_key`, and discard the password immediately.
- The request is forced private with `is_private = 1`.
- The photograph is sent as `uploadedfile` with `has_image = 1`.
- Custom field scalar strings include literal JSON quotes in multipart.
- Do not manually set the multipart `Content-Type`; the browser must generate
  it with the matching boundary.

## M0 exit criteria

All M0 exit criteria are satisfied. Implementation can proceed to M1.
