# M0: capture one real submission

Status: awaiting one legitimate Loudoun County sign-violation submission

The read-only probe is complete. It confirmed that the GitHub Pages origin can
read the PublicStuff metadata and captured the real schema for request type
`1011942`. The only remaining M0 work is to observe the request generated by a
real complaint.

## Capture the submission

1. Wait until you have a truthful sign violation that you intend to report.
2. Open the [official Loudoun County form](https://iframe.publicstuff.com/#/?client_id=1295&request_type_id=1011942) in Chrome on your laptop.
3. Open DevTools and select **Network**.
4. Enable **Preserve log**, select **Fetch/XHR**, and clear the request list.
5. Complete and submit the complaint normally. No login capture is needed; the
   complaint form accepts the required contact information directly.
6. Filter the Network list for `request_submit`.
7. Select the `POST` request to `/api/2.0/request_submit`.
8. Right-click it and choose **Copy → Copy as cURL**.
9. Paste the cURL command into a temporary file outside this repository.
10. In the request's **Response** tab, copy the response JSON to another
    temporary file.
11. If an `OPTIONS` request appears immediately before `request_submit`, record
    its status and these response headers:
    - `Access-Control-Allow-Origin`
    - `Access-Control-Allow-Headers`
    - `Access-Control-Allow-Methods`

The single `request_submit` cURL command and response are preferable to a full
HAR export. A HAR contains unrelated traffic and may embed the uploaded image.

## Sanitize the cURL command

Only the contact information and photograph need to be removed. Replace the
values of these fields while preserving their field names and exact surrounding
encoding:

| Field | Meaning | Replacement |
| --- | --- | --- |
| `custom_field_6185` | First and last name | `[redacted-name]` |
| `custom_field_6186` | Complainant's address | `[redacted-contact-address]` |
| `custom_field_6187` | Email | `[redacted-email]` |
| `custom_field_6225` | Phone | `[redacted-phone]` |
| `uploadedfile` | Photograph | Remove image bytes; retain the field name, filename placeholder, and MIME type |

Keep the remaining request information intact. Client and request IDs, custom
field definitions and choices, CORS headers, complaint location, violation
description, privacy selection, and response structure are public or supplied
by the county form and are useful integration evidence.

In particular, preserve the exact value encoding for fields such as
`custom_field_25876`. We need to see whether a selection is sent as plain text,
a quoted JSON string, an array, or another representation.

## Save the sanitized evidence

After manually confirming that the files contain none of the four contact
values or photograph data, save them as:

```text
docs/publicstuff-request-submit-redacted.txt
docs/publicstuff-request-submit-response.json
```

Include the `OPTIONS` status and headers at the end of the text file if one was
observed. The real PublicStuff request ID may remain in the response.

Do not place the original cURL command, raw image, or an unsanitized HAR in the
repository. Once the sanitized files are saved, delete the temporary originals
and tell Codex to finish M0.
